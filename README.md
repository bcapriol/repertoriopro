# Repertório Fácil Pro

IDENTIDADE DO APLICATIVO



Nome do aplicativo



Repertório Fácil - Bruno Capriolli



Este nome deverá aparecer centralizado na tela inicial do aplicativo, com destaque visual.



Abaixo do título poderá aparecer, em tamanho menor:



Gerenciador de Repertórios Musicais



(opcional, caso harmonize com o layout).



---



TELA INICIAL



A tela inicial deverá possuir um layout limpo, moderno e intuitivo.



Na parte superior:



Repertório Fácil - Bruno Capriolli



Logo abaixo, os cinco botões grandes:



- CADASTRAR MÚSICA

- MÚSICAS SALVAS

- REPERTÓRIOS

- EXPORTAR / IMPORTAR

- MODO ESCURO / CLARO



Os botões devem ocupar praticamente toda a largura da tela, com excelente espaçamento para facilitar o uso durante apresentações.



A interface deve transmitir simplicidade, rapidez e organização, priorizando  a experiência do músico no palco.
